แนวคิด Multicast ในเครือข่าย IP

วิธีการสื่อสารที่มีประสิทธิภาพในการส่งข้อมูลจากแหล่งเดียวไปยังผู้รับหลายราย

แนวคิด Multicast Multicast บน Local LAN Multicast IP to MAC mapping

สรุปความเข้าใจเบื้องต้น

ในเครือข่าย IP มีวิธีการสื่อสารพื้นฐาน 3 รูปแบบ ได้แก่ Unicast, Broadcast และ Multicast โดยแต่ละรูปแบบมีลักษณะเฉพาะและการใช้งานที่แตกต่างกัน

Unicast

การสื่อสารแบบหนึ่งต่อหนึ่ง

Broadcast

การสื่อสารแบบหนึ่งไปหาทั้งหมด

Multicast

การสื่อสารแบบหนึ่งไปหาหลายคน

Unicast คืออะไร?

Unicast เป็นการสื่อสารแบบหนึ่งต่อหนึ่งระหว่างต้นทางและปลายทาง โดยใช้ IP ปลายทางในส่วนหัว Layer 3 ของแพ็กเก็ต

ลักษณะสำคัญของ Unicast:

  • เป็นการสื่อสารแบบหนึ่งต่อหนึ่งระหว่างต้นทางและปลายทาง
  • จำนวนสตรีมข้อมูลเพิ่มขึ้นตามจำนวนผู้รับ
  • มีข้อจำกัดด้านการขยายตัวเมื่อต้องการส่งข้อมูลไปยังผู้รับจำนวนมาก
  • อาจใช้ทรัพยากรมากเกินไปเมื่อต้องส่งสตรีมเดียวกันไปหาผู้รับหลายคน

Broadcast คืออะไร?

Broadcast เป็นวิธีการสื่อสารที่ส่งแพ็กเก็ตไปยังโฮสต์ทั้งหมดในเซกเมนต์เครือข่าย มักเรียกว่า "flooding" เพราะพฤติกรรมการกระจายข้อมูลแบบน้ำท่วม

ลักษณะสำคัญของ Broadcast:

  • ส่งข้อความไปยังโฮสต์ทั้งหมดในเซกเมนต์ แม้ว่าจะไม่ได้ต้องการรับข้อมูล
  • จำกัดอยู่ในเซกเมนต์เครือข่ายท้องถิ่น (Broadcast Domain)
  • เราเตอร์ไม่ส่งต่อข้อความ Broadcast ระหว่างเครือข่าย
  • จำเป็นสำหรับฟังก์ชันเครือข่ายต่างๆ เช่น ARP, DHCP, SNMP และ WoL

Multicast คืออะไร?

Multicast รวมข้อดีของทั้ง Unicast และ Broadcast โดยลดข้อจำกัดของ Broadcast ลง ด้วย Multicast เครือข่ายจะทำสำเนาแพ็กเก็ตและส่งต่อไปยังผู้รับที่สนใจเท่านั้น

ลักษณะสำคัญของ Multicast:

  • ทำสำเนาแพ็กเก็ตและส่งไปยังผู้รับที่สนใจเท่านั้น
  • ผู้รับสามารถอยู่ในเซกเมนต์ IP ใดก็ได้
  • มีประสิทธิภาพสูงในแง่ของการใช้ทรัพยากรเครือข่าย
  • สามารถส่งจากหนึ่งไปหลาย, จากหลายไปหลาย, หรือจากหลายไปหนึ่งได้

การแยกแยะประเภทของการสื่อสาร

อุปกรณ์เครือข่ายใช้ข้อมูลในส่วนหัวของแพ็กเก็ตเพื่อแยกแยะว่าเป็นการสื่อสารประเภท Unicast, Multicast หรือ Broadcast

การแยกแยะใน Layer 2 (สวิตช์)

  • Broadcast: เฟรมที่มี MAC ปลายทางเป็น FFFF.FFFF.FFFF
  • Multicast: MAC ที่มีบิตที่ 8 เป็น "1" ตามมาตรฐาน IEEE 802.3
  • Unicast: MAC ที่มีบิตที่ 8 เป็น "0"

การแยกแยะใน Layer 3 (เราเตอร์)

  • Broadcast: หากที่อยู่ IP ปลายทางเป็นที่อยู่สุดท้ายในซับเน็ต
  • Multicast: หากที่อยู่ IP ปลายทางอยู่ในช่วง 224.0.0.0/4
  • Unicast: หากที่อยู่ IP ปลายทางเป็นที่อยู่ที่ถูกต้อง (ไม่ใช่ที่อยู่แรกหรือสุดท้ายในซับเน็ต)

ที่อยู่ MAC และ IP สำหรับ Multicast

ที่อยู่ MAC สำหรับ Multicast

ที่อยู่ MAC ที่มีบิตที่ 8 เป็น "1" ถือเป็นที่อยู่ MAC แบบ Multicast โดยที่อยู่ MAC แบบ Multicast ทั้งหมดจะอยู่ในช่วง 0x0100.0000.0000 ถึง 0xFFFF.FFFF.FFFF

  • ช่วง 0100.5E00.0000 ถึง 0100.5E7F.FFFF สำรองไว้สำหรับแมปที่อยู่ Multicast IPv4 ไปยังที่อยู่ MAC Ethernet
  • ช่วง 3333.0000.0000 ถึง 3333.FFFF.FFFF สำรองไว้สำหรับ IPv6 Multicast

ที่อยู่ IP สำหรับ Multicast

ที่อยู่ IPv4 แบบ Multicast คือที่อยู่ IP ที่ใช้ในการส่งแพ็กเก็ตไปยังกลุ่มโฮสต์ปลายทางพร้อมกัน โดยอยู่ในช่วงที่เรียกว่า "Class D":

ช่วงที่อยู่ IP Multicast: 224.0.0.0/4 - จาก 224.0.0.0 ถึง 239.255.255.255

ข้อสำคัญ: ที่อยู่ IP แบบ Multicast ไม่สามารถใช้เป็นที่อยู่ IP ต้นทางได้ สามารถใช้เป็นที่อยู่ปลายทางเท่านั้น

คุณลักษณะ Unicast Broadcast Multicast
รูปแบบการสื่อสาร หนึ่งต่อหนึ่ง หนึ่งไปหาทั้งหมด หนึ่งไปหาหลาย
ประสิทธิภาพเมื่อส่งไปยังผู้รับหลายคน ต่ำ (ต้องทำสำเนาหลายรอบ) ปานกลาง (ผู้รับที่ไม่ต้องการก็ได้รับ) สูง (ส่งเฉพาะผู้รับที่สนใจ)
การข้ามเซกเมนต์เครือข่าย สามารถข้ามได้ ไม่สามารถข้ามได้ (ปกติ) สามารถข้ามได้
การใช้งานแบนด์วิดท์ สูงเมื่อมีผู้รับหลายคน ปานกลาง แต่ไม่มีประสิทธิภาพ ประหยัดที่สุด

กรณีการใช้งาน Multicast

การสื่อสารแบบหนึ่งไปหาหลาย (One-to-Many)

  • การสตรีมวิดีโอและเสียงสด
  • บริการทางการเงินสำหรับการกระจายข้อมูลตลาด
  • เกมออนไลน์
  • การกระจายซอฟต์แวร์และอัพเดต
  • โทรคมนาคม (IPTV, การประชุมทางวิดีโอ)
  • การส่งมอบเนื้อหาทางการศึกษา
  • ฟีดข้อมูลแบบเรียลไทม์

การสื่อสารแบบหลายไปหาหนึ่ง (Many-to-One)

  • เครือข่าย IoT และเซ็นเซอร์
  • การควบคุมและจัดการเครือข่าย

การสื่อสารแบบหลายไปหาหลาย (Many-to-Many)

  • โทรคมนาคม (การประชุมทางวิดีโอ)
  • แอปพลิเคชันทางทหารและการป้องกัน

ประเด็นสำคัญที่ควรจำ

  • วิธีการสื่อสารพื้นฐานในเครือข่าย TCP/IP มี 3 รูปแบบ: Unicast, Broadcast, และ Multicast
  • ที่อยู่ MAC ที่มีบิตที่ 8 เป็น 1 คือที่อยู่ MAC แบบ Multicast
  • ที่อยู่ IP ในช่วง Class D (224.0.0.0/4) ใช้สำหรับ Multicast
  • ในการสื่อสารแบบ IP Multicast ไม่มีการใช้ ARP! ที่อยู่ MAC ปลายทางเป็นผลมาจากที่อยู่ IPv4 Multicast
  • ที่อยู่ IP แบบ Multicast ไม่สามารถเป็นที่อยู่ต้นทางได้ ใช้เป็นที่อยู่ปลายทางเท่านั้น

🔍 ภาพรวม Multicast และ PIM

Protocol Independent Multicast (PIM) เป็นโปรโตคอลสำหรับการส่งข้อมูลแบบ Multicast ในเครือข่าย โดยมีลักษณะสำคัญดังนี้:

  • PIM ทำงานอิสระจาก Unicast Routing Protocol สามารถทำงานร่วมกับ EIGRP, OSPF, ISIS, BGP หรือ Static Routes ได้
  • PIM ใช้ข้อมูลที่ได้จาก Unicast Routing Protocol เพื่อสร้าง Multicast Distribution Tree
  • แม้ PIM จะถูกเรียกว่า Multicast Routing Protocol แต่จริงๆแล้วไม่ใช่ "Routing Protocol" เพราะไม่มีการส่งและรับ Routing Updates

⚙️ ขั้นตอนการเปิดใช้งาน Multicast ใน Cisco IOS-XE

1 เปิดใช้งาน Multicast Routing (ตั้งค่าระดับอุปกรณ์)

โดยค่าเริ่มต้น Cisco Routers จะไม่เปิดใช้งาน Multicast Forwarding ต้องเปิดใช้งานด้วยคำสั่ง:

Router# conf t
Router(config)# ip multicast-routing
Router(config)# end

ตรวจสอบสถานะด้วยคำสั่ง:

Router# show ip multicast
ข้อควรจำ:
  • Multicast Routing ปิดใช้งานโดยค่าเริ่มต้นบนอุปกรณ์ Cisco ทั้งหมด
  • ต้องเปิดใช้งานด้วยคำสั่งระดับ Global Configuration
  • ปัญหาทั่วไปของ Multicast คือ Router ไม่ได้เปิดใช้งาน Multicast Routing
2 เปิดใช้งาน PIM (ตั้งค่าระดับ Interface)

PIM ต้องเปิดใช้งานบนแต่ละ Interface ด้วยคำสั่ง:

Router# conf t
Router(config)# interface ethernet0/0
Router(config-if)# ip pim dense-mode
Router(config-if)# end

ตรวจสอบ PIM Neighbors ด้วยคำสั่ง:

Router# show ip pim neighbor

ตรวจสอบ PIM Interface ด้วยคำสั่ง:

Router# show ip pim interface
ข้อควรจำ:
  • PIM ปิดใช้งานโดยค่าเริ่มต้นบนทุก Interface ของอุปกรณ์ Cisco
  • ต้องเปิดใช้งานด้วยคำสั่งระดับ Interface
  • อย่าลืมเปิดใช้งาน PIM บน Interface ที่เชื่อมต่อกับ Source
  • อย่าลืมเปิดใช้งาน PIM บน Interface ที่เชื่อมต่อกับ Receivers
3 ตั้งค่า IGMP Group Membership

เพื่อให้ Receivers สามารถเข้าร่วมกลุ่ม Multicast ใช้คำสั่ง:

Receiver# conf t
Receiver(config)# interface ethernet0/0
Receiver(config-if)# ip igmp join-group 239.1.1.1
Receiver(config-if)# end

🔄 PIM Modes

PIM สามารถทำงานได้ใน 3 โหมด:

โหมด รายละเอียด
PIM Dense Mode ใช้โมเดลแบบ Push เพื่อส่ง Multicast
PIM Sparse Mode ใช้โมเดลแบบ Pull เพื่อส่ง Multicast
PIM Sparse-Dense Mode ผสมของทั้ง 2 โหมด โดยแต่ละกลุ่มสามารถเลือกใช้ Dense หรือ Sparse ได้

📊 PIM Versions

PIM มี 2 เวอร์ชั่น โดยปัจจุบันใช้ Version 2 เป็นหลัก:

เวอร์ชั่น รายละเอียด
PIMv1
  • ใช้รูปแบบแพ็กเก็ตของ IGMP
  • ถือเป็นเวอร์ชั่นเก่าที่ไม่นิยมใช้แล้ว
PIMv2
  • มีหมายเลข IP Protocol เป็นของตัวเอง (103)
  • โหมดการทำงาน (Dense หรือ Sparse) เป็นคุณสมบัติของกลุ่มแทนที่จะเป็นของ Interface
  • เป็นมาตรฐานในเครือข่ายปัจจุบัน

🔄 กระบวนการทำงานของ PIM

PIM Hello Messages:

  • เมื่อเปิดใช้งาน PIM บน Interface, PIM จะเริ่มส่ง Hello Messages ไปยัง Link-Local Multicast Address 224.0.0.13
  • Hello Messages ถูกส่งทุก 30 วินาที โดยมี Hold Timer 105 วินาที (3.5 × Hello)
  • เมื่อ Router อื่นมี PIM-enabled Interface บนเซ็กเมนต์เดียวกัน, Router ทั้งสองจะได้ยินกันและสร้าง PIM Adjacency

📌 PIM States

หลักการสำคัญของ Multicast:

  • Multicast ไหลในทิศทางจาก Source ไปยัง Receiver
  • Multicast Distribution Tree ถูกสร้างในทิศทางจาก Receiver ไปยัง Source
  • การแก้ไขปัญหาควรเริ่มจากทิศทางจาก Receiver ไปยัง Source
  • ไม่มี ECMP (Equal-Cost Multi-Path) มีเพียง FHR (First-Hop Router) และ LHR (Last-Hop Router) เท่านั้นที่มีส่วนร่วมใน Data Plane

ตรวจสอบ Multicast Route Table:

Router# show ip mroute [group-address]

ตรวจสอบ Multicast Forwarding Information Base:

Router# show ip mfib [group-address]

🚀 สรุปประเด็นสำคัญ

  1. Multicast Routing ปิดใช้งานโดยค่าเริ่มต้นบนอุปกรณ์ Cisco ทั้งหมด ต้องเปิดใช้งานด้วยตนเอง
  2. Router จะไม่ส่งต่อ Multicast Traffic ระหว่าง Interface หาก Multicast Routing ไม่ได้เปิดใช้งาน
  3. Router ส่งต่อ Multicast Traffic เฉพาะระหว่าง PIM-enabled Interfaces เท่านั้น
  4. PIM เปิดใช้งานแยกตาม Interface และปิดใช้งานโดยค่าเริ่มต้น
  5. PIMv2 เป็นมาตรฐานและค่าเริ่มต้นบนทุกอุปกรณ์ Cisco IOS-XE ในปัจจุบัน
  6. ความแตกต่างหลักระหว่าง PIMv1 และ PIMv2 คือรูปแบบแพ็กเก็ต

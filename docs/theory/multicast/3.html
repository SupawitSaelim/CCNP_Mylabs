การแปลง Multicast IP เป็น MAC Address

แนวคิด Multicast Multicast บน Local LAN Multicast IP to MAC mapping

บทนำ

เอกสารนี้อธิบายกระบวนการแปลงหมายเลข IP Address แบบ Multicast ไปเป็น MAC Address สิ่งสำคัญที่ต้องเข้าใจคือ อุปกรณ์เครือข่ายทำงานกับ IP และ MAC Address ในรูปแบบเลขฐานสอง (Binary) เท่านั้น โดย IP Address มีขนาด 32 บิต ส่วน MAC Address มีขนาด 48 บิต การแสดงผลในรูปแบบเลขฐานสิบ (Decimal) สำหรับ IP Address และเลขฐานสิบหก (Hexadecimal) สำหรับ MAC Address เป็นเพียงรูปแบบที่ทำให้มนุษย์อ่านง่ายขึ้นเท่านั้น

โครงสร้างของ Multicast IP Address

IP Address มีขนาด 32 บิต แบ่งเป็น 4 ชุด (Octet) ชุดละ 8 บิต สำหรับ IP Multicast จะใช้ Class D Address Range โดย 4 บิตแรกของ Octet แรกจะถูกกำหนดค่าตายตัวเป็น 1110 ซึ่งแสดงด้วยสัญลักษณ์ 224.0.0.0/4 โดย /4 หมายความว่า 4 บิตแรกถูกกำหนดค่าคงที่เป็น 1110 เสมอ


รูปที่ 1: โครงสร้าง Multicast IP Address

โครงสร้างแบบนี้ทำให้ช่วง IP ที่ใช้สำหรับ Multicast คือ 224.0.0.0 - 239.255.255.255 ซึ่งในรูปแบบเลขฐานสองจะเป็น:

เริ่มจาก
11100000.00000000.00000000.00000000 (224.0.0.0)
ถึง
11101111.11111111.11111111.11111111 (239.255.255.255)

สังเกตว่าส่วนที่เป็นสีแดงคือบิตที่ถูกกำหนดค่าคงที่และไม่เปลี่ยนแปลง

โครงสร้างของ Multicast MAC Address

MAC Address มีขนาด 48 บิต แบ่งเป็น 6 ชุด (Octet) ชุดละ 8 บิต สำหรับ IP Multicast จะใช้ MAC Address Prefix คือ 0x0100.5E โดย 25 บิตแรกจะถูกกำหนดค่าตายตัวเป็น 00000001.00000000.01011110.0


รูปที่ 2: โครงสร้าง Multicast MAC Address

โครงสร้างนี้ทำให้ช่วง Ethernet MAC Address ที่ใช้สำหรับ Multicast คือ 0100.5E00.0000 ถึง 0100.5E7F.FFFF ซึ่งในรูปแบบเลขฐานสองจะเป็น:

เริ่มจาก
00000001.00000000.01011110.00000000.00000000.00000000
ถึง
00000001.00000000.01011110.01111111.11111111.11111111

สังเกตว่าส่วนที่เป็นสีแดงคือบิตที่ถูกกำหนดค่าคงที่และไม่เปลี่ยนแปลง

การแปลง Multicast IP เป็น MAC

กระบวนการแปลง Multicast IP Address เป็น MAC Address คือการนำ 23 บิตสุดท้ายของ IP Address ไปใส่ใน 23 บิตสุดท้ายของ Ethernet Multicast Address


รูปที่ 3: การแปลง Multicast IP เป็น MAC

สิ่งสำคัญที่ต้องสังเกตในกระบวนการนี้:

  • Multicast IP Address ประกอบด้วย 4 บิตคงที่ (Multicast IP Prefix สีแดง) และ 28 บิตที่เปลี่ยนแปลงได้
  • Multicast MAC Address ประกอบด้วย 25 บิตคงที่ (Multicast MAC Prefix สีแดง) และ 23 บิตที่เปลี่ยนแปลงได้
  • เนื่องจาก Multicast MAC มีเพียง 23 บิตที่ไม่คงที่ จึงสามารถนำเพียง 23 บิตของ IP Address มาแมปลงใน MAC Address ได้ ทำให้มี 5 บิตของ IP Address (สีเทา) ที่ไม่สามารถแมปได้

ซึ่งหมายความว่า ไม่มี Multicast MAC Address เพียงพอที่จะแมปกับทุก Multicast IP Address เนื่องจากไม่มีพื้นที่เพียงพอที่จะแมป 28 บิตที่เปลี่ยนแปลงได้ของ Multicast IP Address ลงใน 23 บิตที่เปลี่ยนแปลงได้ของ Multicast MAC Address ในทางปฏิบัติ นี่หมายความว่า 2^5 (32) IP Address จะแมปไปยัง MAC Address เดียวกัน


รูปที่ 4: 32 Multicast IP Address แมปไปยัง MAC เดียวกัน

ผลกระทบในทางปฏิบัติ

ผลกระทบในทางปฏิบัติของความไม่มีประสิทธิภาพในการแมปนี้คือ โฮสต์อาจได้รับ Multicast Frame ที่ระดับ Ethernet สำหรับกลุ่ม IP Multicast ที่แตกต่างกันซึ่งตรงกับ MAC Address เดียวกัน

สวิตช์ LAN ทำสำเนา Multicast โดยการแมป Multicast MAC Address ไปยังพอร์ตของสวิตช์ที่มีผู้รับที่สนใจเชื่อมต่ออยู่ อย่างไรก็ตาม เนื่องจาก MAC Address หนึ่งแทน 32 Multicast IP Address โฮสต์ที่สนใจรับ Multicast บนกลุ่ม 1 จะได้รับ Multicast Stream หลายรายการจาก 31 IP Address อื่นที่ตรงกับ MAC เดียวกัน เนื่องจากสวิตช์ LAN ดูเฉพาะส่วนหัว Layer 2 และ Destination MAC Address เดียวกันสำหรับ 32 Destination Multicast IP


รูปที่ 5: ความไม่มีประสิทธิภาพของ Multicast MAC

ในที่สุด ผู้รับทั้งสองฝั่ง (PC2 และ PC4) จะได้รับทั้งสองสตรีม แม้ว่าแต่ละฝั่งต้องการเพียงหนึ่งในสตรีมเท่านั้น ความไม่มีประสิทธิภาพนี้เพิ่มภาระให้กับเครือข่ายและโฮสต์ปลายทางพร้อมกัน

วิธีหลีกเลี่ยงปัญหานี้

วิธีที่มีประสิทธิภาพมากที่สุดในการหลีกเลี่ยงปัญหานี้คือ ตรวจสอบให้แน่ใจว่าแอปพลิเคชันไม่ใช้หมายเลข IPv4 แบบ Multicast ที่ตรงกับ Multicast MAC Address เดียวกัน ตัวอย่างเช่น หากแอปพลิเคชันหนึ่งใช้ที่อยู่ Multicast 239.1.1.1 ให้ตรวจสอบว่า 31 IPv4 Address อื่นที่ตรงกับ MAC 0100.5E01.0101 ไม่ถูกใช้

ในปัจจุบัน สวิตช์สมัยใหม่ส่งต่อ Multicast Traffic ตาม Destination MAC และ Destination IPv4 Address แม้จะทำหน้าที่เป็นเพียง Layer 2 Ethernet Bridge ซึ่งช่วยบรรเทาปัญหานี้และทำให้อุปกรณ์สามารถทำสำเนา Multicast Traffic ไปยังผู้รับที่สนใจที่เชื่อมต่ออยู่เท่านั้น อย่างไรก็ตาม ไม่ใช่ทุกแพลตฟอร์มและผู้ผลิตจะรองรับความสามารถนี้ ดังนั้นวิธีที่แนะนำคือหลีกเลี่ยงการใช้ Multicast IP/MAC Address ที่ทับซ้อนกัน

การแปลง Multicast IP เป็น MAC Address

คุณอาจจะไม่จำเป็นต้องแปลง Multicast IP Address เป็น Multicast MAC Address ด้วยตนเอง แต่เพื่อให้เข้าใจแนวคิดได้ง่ายขึ้น เรามาดูวิธีการแปลงหมายเลข 239.5.5.5 เป็น Multicast MAC Address กัน

แปลง Multicast IP เป็นเลขฐานสอง

239.5.5.5 = 11101111.00000101.00000101.00000101
ส่วนสีน้ำเงินคือ 23 บิตสุดท้าย

นำ 23 บิตสุดท้ายไปแมปกับ Multicast MAC Prefix ที่รู้จักกันทั่วไป

Multicast MAC Prefix คือ 00000001.00000000.01011110.0xxxxxxx.xxxxxxxx.xxxxxxxx
ส่วนสีแดงคือบิต Prefix ที่คงที่

แมป 23 บิตสุดท้ายของ IP (สีน้ำเงิน) ลงใน MAC Prefix (สีแดง)
ผลลัพธ์คือ 00000001.00000000.01011110.00000101.00000101.00000101

แปลงผลลัพธ์เป็นเลขฐานสิบหก (HEX)

0x0100.5E05.0505

นี่คือ MAC Address ที่จะถูกใช้เมื่อส่งไปยังกลุ่ม 239.5.5.5

การแปลง Multicast MAC เป็น IP Address

สำหรับการดำเนินการย้อนกลับ เรามาลองแปลง Multicast MAC 0100.5E07.FE01 เป็นชุด IP Address ที่เกี่ยวข้อง

แปลง Multicast MAC เป็นเลขฐานสอง

0x0100.5E07.FE01 = 00000001.00000000.01011110.00000111.11111110.00000001

นำ 23 บิตสุดท้ายไปแมปกับ Multicast IP Prefix ที่รู้จักกันทั่วไป

Multicast IP Prefix คือ 1110yyyyy.yxxxxxxx.xxxxxxxx.xxxxxxxx
ส่วนสีแดงคือบิต Prefix ที่คงที่ ส่วนสีเขียวคือ 5 บิตที่สูญหายระหว่างการแปลง
เราตั้งค่าเป็น 0 เพื่อหา IP Address แรกจากทั้งหมด 32 Address

แมป 23 บิตสุดท้าย (สีน้ำเงิน) ลงใน IP Prefix (สีแดง)
ผลลัพธ์คือ 111000000.00000111.11111110.00000001

แปลงผลลัพธ์เป็นเลขฐานสิบ (Decimal)

224.7.254.1

นี่คือ IP Address แรกจาก 32 Address ที่ตรงกับ 0100.5E07.FE01

หา 31 IP Address ที่เหลือ

เมื่อเราเพิ่ม +128 ให้กับ Octet ที่สอง แล้วเพิ่ม +1 ให้กับ Octet แรก โดยทำซ้ำ
ที่ 2 -> 224.(7+128).254.1 = 224.135.254.1
ที่ 3 -> 225.7.254.1
ที่ 4 -> 225.135.254.1
ที่ 5 -> 226.7.254.1
.
ที่ 31 -> 239.7.254.1
ที่ 32 -> 239.135.254.1

IGMP Snooping

แนวคิด Multicast Multicast บน Local LAN Multicast IP to MAC mapping IGMP IGMP Snooping

สรุปสาระสำคัญ

IGMP Snooping คือฟีเจอร์ที่ช่วยให้สวิตช์สามารถตรวจสอบและเฝ้าสังเกตการสื่อสารระหว่างโฮสต์และเราท์เตอร์มัลติคาสต์ภายใน VLAN ทำให้สามารถส่งข้อมูลมัลติคาสต์เฉพาะไปยังพอร์ตที่มีผู้รับที่สนใจเท่านั้น ช่วยลดการใช้แบนด์วิดท์และเพิ่มประสิทธิภาพของเครือข่าย

IGMP Snooping คืออะไร?

IGMP Snooping เป็นฟีเจอร์ที่ช่วยให้สวิตช์สามารถตรวจสอบการสื่อสารระหว่างอุปกรณ์ต่างๆ ผ่านข้อความ IGMP เพื่อเรียนรู้ว่าพอร์ตใดมีผู้รับที่สนใจกลุ่มมัลติคาสต์ใดบ้าง และพอร์ตใดเชื่อมต่อกับเราท์เตอร์มัลติคาสต์

ทำไมต้องใช้ IGMP Snooping?

หากไม่มี IGMP Snooping สวิตช์จะไม่ทราบว่าพอร์ตใดมีผู้รับที่สนใจกลุ่มมัลติคาสต์เฉพาะ ดังนั้นจะทำการส่งข้อมูลมัลติคาสต์เหมือนกับข้อมูลบรอดคาสต์ ซึ่งจะถูกส่งไปยังทุกพอร์ตใน VLAN ทำให้สิ้นเปลืองแบนด์วิดท์และอาจทำให้เกิดปัญหาด้านประสิทธิภาพในเครือข่ายขนาดใหญ่

รูปที่ 1: เครือข่าย LAN ที่ไม่มี IGMP Snooping ข้อมูลมัลติคาสต์จะถูกส่งไปยังทุกพอร์ต

IGMP Snooping ทำงานอย่างไร?

IGMP Snooping จะถูกเปิดใช้งานบนสวิตช์ตาม VLAN เมื่อเปิดใช้งานฟีเจอร์นี้ สวิตช์จะคอยฟังข้อความต่อไปนี้ภายใน VLAN:

  • IGMP Membership Queries - คำขอจากเราท์เตอร์มัลติคาสต์
  • IGMP Membership Responses - การตอบกลับจากโฮสต์
  • PIM Hello messages - ข้อความแจ้งสถานะจากโปรโตคอล PIM

จากการตรวจสอบข้อความ IGMP สวิตช์จะสร้างตาราง "IGMP snooping table" ที่จัดประเภทพอร์ตเป็น 2 ประเภท:

  • multicast-router interface - พอร์ตที่เชื่อมต่อไปยังเราท์เตอร์มัลติคาสต์หรือ IGMP querier
  • group-member interface - พอร์ตที่เชื่อมต่อไปยังผู้รับที่สนใจ

สิ่งสำคัญ: จำเป็นต้องมี IGMP querier อยู่ใน VLAN (ซึ่งมักเป็นเราท์เตอร์มัลติคาสต์) เพื่อให้ IGMP Snooping ทำงานได้อย่างถูกต้อง

ขั้นตอนการทำงานของ IGMP Snooping

ขั้นตอนที่ 1: การค้นหาพอร์ตเราท์เตอร์มัลติคาสต์

  • IGMP querier (เราท์เตอร์ R1) ส่ง IGMP Membership Queries ไปยังที่อยู่ all-hosts link-local 224.0.0.1
  • เมื่อสวิตช์ SW1 ได้รับ query จะเพิ่มพอร์ต 0/1 เข้าไปในตาราง IGMP snooping เป็นพอร์ต mrouter
  • จากนั้นจะส่งต่อ IGMP query ไปยังทุกพอร์ตเพื่อให้โฮสต์ได้รับ
  • SW2 จะได้รับ IGMP query บนพอร์ต 0/2 และเพิ่มเข้าไปในตารางเป็นพอร์ตเราท์เตอร์ จากนั้นส่งต่อข้อความไปยังทุกพอร์ต
รูปที่ 2: การค้นหาพอร์ตเราท์เตอร์มัลติคาสต์ใน IGMP Snooping

ขั้นตอนที่ 2: การค้นหาพอร์ตสมาชิก

  • PC1 และ PC4 ตอบกลับ IGMP Membership Query ด้วย Membership Report สำหรับกลุ่ม 239.1.1.1
  • SW1 ได้รับรายงานจาก PC1 บนพอร์ต 0/3 และเพิ่มพอร์ตเข้าไปในตารางเป็นสมาชิกของกลุ่ม 239.1.1.1
  • SW1 ส่งรายงานไปยังพอร์ตเราท์เตอร์ที่นำไปสู่เราท์เตอร์มัลติคาสต์เท่านั้น
  • SW2 ได้รับรายงานจาก PC4 บนพอร์ต 0/4 และทำเช่นเดียวกัน
  • สังเกตว่า PC2 และ PC3 จะไม่ได้รับรายงานจาก PC1 และ PC4 นี่คือการเพิ่มประสิทธิภาพแรกของ IGMP Snooping
รูปที่ 3: การค้นหาพอร์ตสมาชิกใน IGMP Snooping

ผลลัพธ์จากสองขั้นตอนนี้ ทำให้สวิตช์ทั้งสอง (SW1 และ SW2) รู้ว่าพอร์ตใดเชื่อมต่อกับผู้รับที่สนใจและเราท์เตอร์มัลติคาสต์ เมื่อ R1 ส่งข้อมูลมัลติคาสต์ไปยัง LAN สวิตช์จะส่งต่อข้อมูลนี้เฉพาะไปยังพอร์ต mrouter และพอร์ตสมาชิกตามตาราง IGMP snooping

รูปที่ 4: ประสิทธิภาพของ IGMP Snooping - ข้อมูลมัลติคาสต์ถูกส่งเฉพาะไปยังพอร์ตที่ต้องการ

รายการในตาราง IGMP Snooping จะมีเวลาหมดอายุ หากไม่ได้รับข้อความ IGMP สำหรับกลุ่มมัลติคาสต์เฉพาะภายในระยะเวลาหนึ่ง สวิตช์จะลบรายการนั้นออกจากตาราง

การกำหนดค่า IGMP Snooping

IGMP snooping เปิดใช้งานบนทุก VLAN โดยค่าเริ่มต้นบนสวิตช์ Cisco รุ่นใหม่ทั้งหมด แต่เราสามารถกำหนดค่าและตรวจสอบฟีเจอร์นี้ได้

ข้อกำหนดเบื้องต้น

ต้องมี IGMP Querier ใน VLAN ซึ่งมักเป็นเราท์เตอร์มัลติคาสต์ในเซกเมนต์ เมื่อกำหนดค่า PIM บนอินเตอร์เฟซ IGMP จะถูกเปิดใช้งานโดยอัตโนมัติ

รูปที่ 5: การกำหนดค่า IGMP Snooping

คำสั่งการกำหนดค่า IGMP Snooping

SW1(config)# ip igmp snooping vlan 10 // เปิดใช้งาน IGMP snooping บน VLAN 10
SW1(config)# no ip igmp snooping vlan 10 // ปิดใช้งาน IGMP snooping บน VLAN 10

การกำหนดค่าพอร์ต mrouter และสมาชิกแบบคงที่

เราสามารถกำหนดพอร์ต mrouter แบบคงที่ได้ด้วยคำสั่งต่อไปนี้:

SW1(config)# ip igmp snooping vlan 10 mrouter interface Ethernet 1/0

เพื่อตรวจสอบพอร์ต mrouter:

SW1# sh ip igmp snooping mrouter vlan 10
Vlan ports
---- -----
10 Et0/0(dynamic), Et1/0(static)

การกำหนดค่าอินเตอร์เฟซสมาชิกแบบคงที่:

SW1(config)# ip igmp snooping vlan 10 static 239.2.2.2 interface Et1/1

คำสั่งการตรวจสอบ

ตรวจสอบว่าฟีเจอร์เปิดใช้งานอยู่:

SW1# sh ip igmp snooping vlan 10

ตรวจสอบพอร์ต mrouter:

SW1# sh ip igmp snooping mrouter
SW1# show ip igmp snooping querier

ตรวจสอบพอร์ตสมาชิกและกลุ่ม:

SW1# sh ip igmp snooping groups

พารามิเตอร์เพิ่มเติมของ IGMP Snooping

Report Suppression

เมื่อโฮสต์หลายเครื่องบน VLAN เดียวกันต้องการเข้าร่วมกลุ่มมัลติคาสต์เดียวกัน IGMP Snooping Report Suppression ช่วยให้เฉพาะรายงานแรกเท่านั้นถูกส่งต่อไปยังเราท์เตอร์มัลติคาสต์ รายงานที่ตามมาจากโฮสต์อื่นๆ จะถูกระงับ (ไม่ส่งต่อ)

SW1(config)# no ip igmp snooping report-suppression // ปิดใช้งาน Report Suppression

IGMP Snooping Querier

ในสถานการณ์ที่ไม่มีเราท์เตอร์มัลติคาสต์ใน VLAN เราสามารถกำหนดค่าให้สวิตช์ LAN ทำหน้าที่เป็น IGMP querier สำหรับเซกเมนต์ได้

รูปที่ 6: IGMP Snooping Querier - สวิตช์ทำหน้าที่เป็นตัวส่ง Query

สรุปสำคัญของ IGMP Snooping

  • จุดประสงค์: ช่วยให้สวิตช์จัดการข้อมูลมัลติคาสต์ใน LAN อย่างชาญฉลาดโดยการเรียนรู้แบบไดนามิกว่าพอร์ตใดมีผู้รับที่สนใจและส่งข้อมูลมัลติคาสต์เฉพาะไปยังพอร์ตเหล่านั้น
  • ประโยชน์: เพิ่มประสิทธิภาพเครือข่าย ลดการจราจรที่ไม่จำเป็น และปรับปรุงประสิทธิภาพโดยรวมในสภาพแวดล้อมที่มีข้อมูลมัลติคาสต์
  • ข้อกำหนดเบื้องต้น: ต้องมี IGMP Querier ใน VLAN
  • ประเภทของพอร์ต: multicast-router interface และ group-member interface
  • ฟีเจอร์เพิ่มเติม: Report Suppression และ IGMP Snooping Querier

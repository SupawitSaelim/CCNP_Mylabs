โปรโตคอล IGMP (Internet Group Management Protocol)

แนวคิด Multicast Multicast บน Local LAN Multicast IP to MAC mapping IGMP IGMP Snooping PIM Dense Mode Summary Commands

สรุปสาระสำคัญ

IGMP คือโปรโตคอลที่ใช้สำหรับการจัดการกลุ่มมัลติคาสต์ในเครือข่าย IPv4 โดยทำหน้าที่เป็นตัวกลางในการสื่อสารระหว่างอุปกรณ์ต้นทางและเราท์เตอร์มัลติคาสต์ในการแจ้งความต้องการรับหรือหยุดรับข้อมูลมัลติคาสต์

ทำไมต้องใช้ IGMP?

เมื่อเราท์เตอร์มัลติคาสต์ได้รับข้อมูลมัลติคาสต์จากแหล่งที่มา เราท์เตอร์จำเป็นต้องรู้ว่าควรส่งข้อมูลนี้ไปยังเซกเมนต์เครือข่ายใดบ้าง เพื่อให้ถึงอุปกรณ์ที่ต้องการรับข้อมูลเหล่านั้น โดย IGMP จะช่วยให้เราท์เตอร์สามารถตรวจสอบว่ามีอุปกรณ์ใดในเครือข่ายที่สนใจรับข้อมูลมัลติคาสต์จากกลุ่มที่ระบุหรือไม่

รูปที่ 1: แสดงการทำงานของ IGMP ในเครือข่าย

IGMPv1 (IGMP เวอร์ชัน 1)

IGMPv1 ถูกแนะนำในปี 1989 ผ่าน RFC 1112 โดยมีกลไกพื้นฐานแบบคำถาม-คำตอบที่ช่วยให้เราท์เตอร์มัลติคาสต์สามารถตรวจสอบว่ามีอุปกรณ์ใดที่ต้องการรับข้อมูลมัลติคาสต์

รูปที่ 2: ภาพรวมการทำงานของ IGMPv1

ข้อความหลักของ IGMPv1

ประเภทข้อความ คำอธิบาย
Membership Query เราท์เตอร์มัลติคาสต์ส่งคำขอไปยังที่อยู่ 224.0.0.1 (all hosts local multicast) เพื่อตรวจสอบว่ามีโฮสต์ใดต้องการเป็นสมาชิกของกลุ่มมัลติคาสต์ ช่วงเวลาค่าเริ่มต้นในการส่ง Query คือทุก 60 วินาที
Membership Report โฮสต์ที่ต้องการรับข้อมูลมัลติคาสต์จะตอบกลับด้วย Membership Report ทุกครั้งที่ได้รับ Query

ข้อด้อยของ IGMPv1

IGMPv1 ไม่มีกลไกสำหรับการออกจากกลุ่ม (Leave Group) เมื่อโฮสต์ไม่ต้องการรับข้อมูลมัลติคาสต์อีกต่อไป โฮสต์จะหยุดตอบกลับข้อความ Membership Query จากเราท์เตอร์ เราท์เตอร์จะรอเวลา 3 เท่าของ Query-interval (180 วินาที) จึงจะหยุดส่งข้อมูลมัลติคาสต์ไปยังเซกเมนต์นั้น

สรุปสำคัญของ IGMPv1

  • จุดประสงค์: เป็นโปรโตคอลแบบคำถาม-คำตอบอย่างง่ายที่ช่วยให้เราท์เตอร์สามารถตรวจสอบกลุ่มมัลติคาสต์ที่มีสมาชิกใช้งานอยู่ในเครือข่ายที่เชื่อมต่อโดยตรง
  • ประเภทข้อความ:
    • Membership Query: เราท์เตอร์ส่งข้อความ Query เพื่อตรวจสอบผู้รับข้อมูลมัลติคาสต์
    • Membership Report: โฮสต์ตอบกลับด้วย Report เมื่อต้องการเข้าร่วมกลุ่มมัลติคาสต์
  • ข้อด้อย: ไม่มีข้อความสำหรับการออกจากกลุ่ม ทำให้การจัดการทรัพยากรเครือข่ายไม่มีประสิทธิภาพ
  • การใช้งาน: IGMPv1 ถือเป็นเทคโนโลยีเก่าและไม่ได้ใช้งานอีกต่อไป อุปกรณ์ Cisco ใช้ IGMP เวอร์ชัน 2 เป็นค่าเริ่มต้น
  • โครงสร้างแพ็คเก็ต: ข้อความ IGMPv1 จะถูกห่อหุ้มภายในแพ็คเก็ต IP โดยไม่ใช้ส่วนหัวของชั้น Transport

การตั้งค่า VLAN บนพอร์ตของสวิตช์

คำสั่งหลักที่ใช้

1. switchport access vlan

กำหนด VLAN ที่จะเชื่อมต่อกับพอร์ตนั้น เช่น switchport access vlan 100 จะตั้งค่าพอร์ตให้เชื่อมต่อกับ VLAN 100

2. switchport host

เป็น macro ใน Cisco IOS ที่ทำการตั้งค่าพอร์ตในลักษณะดังนี้:

  • กำหนดให้พอร์ตอยู่ใน Access Mode
  • เปิด Spanning Tree PortFast
  • ปิดการใช้งาน EtherChannel

ขั้นตอนการตั้งค่า

ตั้งค่าพอร์ตใน Switch ALS1 และ ALS2

ALS1(config)# interface range fastethernet 0/1 - 5
ALS1(config-if-range)# switchport access vlan 100
ALS1(config-if-range)# switchport host
ALS1(config-if-range)# end

ALS2(config)# interface range fastethernet 0/1 - 5
ALS2(config-if-range)# switchport access vlan 100
ALS2(config-if-range)# switchport host
ALS2(config-if-range)# end

การตรวจสอบการตั้งค่าพอร์ต

1. ดูการตั้งค่าปัจจุบันของพอร์ต

ALS1# show running-config interface fastethernet 0/1

ผลลัพธ์ที่ได้จะเป็นการแสดงว่า:

  • VLAN ที่พอร์ตเชื่อมต่อ (ในที่นี้คือ VLAN 100)
  • Access Mode และ PortFast ถูกเปิดใช้งาน

2. ตรวจสอบสถานะของพอร์ต

ALS1# show interfaces fastethernet 0/1 switchport

ผลลัพธ์:

  • Administrative Mode: static access
  • Operational Mode: static access
  • Access Mode VLAN: 100
  • Spanning-tree PortFast: enabled

สรุปคำสั่ง

  • switchport access vlan <VLAN_ID>: กำหนด VLAN สำหรับพอร์ต
  • switchport host: ตั้งค่าพอร์ตให้เป็น Access Mode เปิด PortFast และปิด EtherChannel

การตั้งค่าเหล่านี้จะช่วยให้พอร์ตสามารถทำงานในโหมด Access และสามารถเชื่อมต่อกับ VLAN ที่ต้องการได้ทันที โดยไม่ต้องรอเวลาในการ converging ของ Spanning Tree

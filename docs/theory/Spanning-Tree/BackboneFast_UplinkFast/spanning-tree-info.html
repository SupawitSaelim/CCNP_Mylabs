Spanning-Tree BackboneFast และ UplinkFast

Spanning-Tree BackboneFast และ Spanning-Tree UplinkFast เป็นคุณสมบัติที่ช่วยเร่งกระบวนการ Convergence ของ Spanning Tree Protocol (STP) เพื่อลดเวลาที่พอร์ตต้องรออยู่ในสถานะ Listening และ Learning ก่อนจะกลายเป็น Forwarding

1. Spanning-Tree UplinkFast

UplinkFast ใช้สำหรับลดเวลาในการ Convergence เมื่อเกิด Direct Link Failure (เช่น สาย Uplink หลุด)

หลักการทำงาน

  • ปกติ ถ้าพอร์ต Root Port หลุด STP ต้องรอ 30–50 วินาทีเพื่อเปลี่ยนไปใช้พอร์ตสำรอง
  • UplinkFast จะช่วยให้พอร์ตสำรอง (Blocking) สามารถกลายเป็น Forwarding ได้ทันทีโดยไม่ต้องรอ Listening/Learning
  • เมื่อเกิด Direct Link Failure สวิตช์จะเปลี่ยนพอร์ตที่ไม่ใช่ Designated Port (Non-Designated Port) ให้เป็น Root Port และเข้าสู่สถานะ Forwarding ทันที
  • สวิตช์จะส่ง dummy multicast frames ออกไปเพื่อบอกอุปกรณ์อื่นให้ลบ MAC Address เก่าที่อาจยังค้างอยู่ในตาราง
  • ควรเปิดใช้งานบนสวิตช์ที่มี Non-Designated Ports เช่น Access Layer Switch

คำสั่งเปิดใช้งาน

Switch(config)# spanning-tree uplinkfast

2. Spanning-Tree BackboneFast

BackboneFast ใช้สำหรับลดเวลาในการ Convergence เมื่อเกิด Indirect Link Failure (เช่น สวิตช์ตัวกลางล่ม)

หลักการทำงาน

  • ปกติ STP ต้องรอ MaxAge (20 วินาที) ก่อนจะเริ่มคำนวณใหม่เมื่อ BPDU จาก Root Bridge หายไป
  • BackboneFast จะช่วยให้สวิตช์สามารถตรวจจับ Indirect Link Failure ได้เร็วขึ้นโดยใช้ Root Link Query (RLQ)
  • เมื่อตรวจพบ Inferior BPDU จากสวิตช์ข้างเคียง (หมายถึง BPDU ที่ระบุว่า Root Bridge เปลี่ยนไปแล้ว แต่จริง ๆ ยังไม่เปลี่ยน)
    1. สวิตช์จะส่ง RLQ Request เพื่อยืนยันว่า Root Bridge ยังมีอยู่หรือไม่
    2. ถ้า Root Bridge ยังอยู่จริง จะมีการส่ง RLQ Response กลับมา
    3. สวิตช์จะข้ามช่วง Max Age Timer และเปลี่ยนพอร์ตที่ไม่ใช่ Designated Port (Non-Designated Port) ให้เป็น Designated Port (เข้าสู่ Listening State) ทันที
  • ควรเปิดใช้งานบนทุกสวิตช์ในเครือข่ายเพื่อให้ทำงานได้อย่างสมบูรณ์

คำสั่งเปิดใช้งาน

Switch(config)# spanning-tree backbonefast

สรุปความแตกต่าง

Feature ใช้เมื่อเกิด วิธีช่วยให้ Convergence เร็วขึ้น เหมาะกับ
UplinkFast Direct Link Failure
(สาย Uplink หลุด)		 เปลี่ยนพอร์ตสำรอง (Non-Designated Port) ให้เป็น Root Port และเข้าสู่ Forwarding ทันที สวิตช์ Access Layer ที่มี Non-Designated Ports
BackboneFast Indirect Link Failure
(สวิตช์ตัวกลางล่ม)		 ใช้ RLQ Request/Response เพื่อตรวจสอบ Root Bridge และข้าม Max Age Timer ควรเปิดบนทุกสวิตช์ในเครือข่าย

Root Guard ในระบบ Spanning Tree Protocol

การปกป้องโครงสร้างเครือข่ายจากการเปลี่ยนแปลง Root Bridge ที่ไม่ได้ตั้งใจ

Root Guard คืออะไร?

Root Guard เป็นฟีเจอร์ของ Spanning Tree Protocol (STP) ที่ใช้ป้องกัน Designated Port ไม่ให้กลายเป็น Root Port หากได้รับ Superior BPDU (BPDU ที่ Priority ดีกว่า Root Bridge ปัจจุบัน)

  • ถ้าพอร์ตที่เปิดใช้ Root Guard ได้รับ Superior BPDU → มันจะเข้าสู่ Root Inconsistent State และหยุดส่งทราฟฟิก
  • เมื่อไม่มี Superior BPDU เข้ามาอีก → พอร์ตจะกลับมาทำงานอัตโนมัติ

Root Guard ใช้กับพอร์ตไหน?

ใช้กับพอร์ตที่เป็น Designated Port เท่านั้น

  • Designated Port → ต้องการป้องกันไม่ให้ถูกเปลี่ยนเป็น Root Port
  • ห้ามใช้กับ Root Port หรือ Alternate Port
คำเตือน: การใช้ Root Guard กับพอร์ตที่ไม่ใช่ Designated Port อาจทำให้การทำงานของ STP ผิดพลาดและส่งผลให้เครือข่ายไม่เสถียร

วิธีการตั้งค่า Root Guard

ใช้คำสั่งต่อไปนี้ในโหมด interface configuration

Switch(config)# interface <interface> Switch(config-if)# spanning-tree guard root

ถ้าต้องการตั้งค่าหลายพอร์ตพร้อมกัน

Switch(config)# interface range <interface1>, <interface2>, ... Switch(config-if-range)# spanning-tree guard root

การทดสอบ Root Guard

1 ตรวจสอบพอร์ตที่มี Root Guard
Switch# show running-config | include spanning-tree guard root
2 ตั้งค่า Priority ของ VLAN ต่ำลงบนสวิตช์อื่นเพื่อส่ง Superior BPDU
OtherSwitch(config)# spanning-tree vlan <VLAN_ID> priority 0
3 ตรวจสอบว่าพอร์ตถูกบล็อคหรือไม่
Switch# show spanning-tree inconsistentports

ถ้าพอร์ตถูกบล็อค จะขึ้น Root Inconsistent

4 ตรวจสอบสถานะพอร์ตที่ถูกบล็อค
Switch# show spanning-tree interface <interface>

พอร์ตที่ถูกบล็อคจะอยู่ในสถานะ BKN (Broken) และขึ้น ROOT_Inc (Root Inconsistent)

วิธีแก้ไขพอร์ตที่ถูกบล็อค

1 ลบ Root Guard ออกจากพอร์ต (ถ้าจำเป็นต้องเปลี่ยน Root Bridge)
Switch(config)# interface <interface> Switch(config-if)# no spanning-tree guard root
2 ตรวจสอบว่าไม่มี Superior BPDU ส่งเข้ามาอีก
3 รอให้พอร์ตกลับมาทำงานอัตโนมัติ หรือใช้คำสั่ง shutdown และ no shutdown รีเซ็ตพอร์ต
Switch(config)# interface <interface> Switch(config-if)# shutdown Switch(config-if)# no shutdown
คำแนะนำเพิ่มเติม: ควรมีการวางแผนและออกแบบโครงสร้าง STP ที่ดีตั้งแต่แรก เพื่อหลีกเลี่ยงการเปลี่ยนแปลง Root Bridge ที่อาจส่งผลกระทบต่อประสิทธิภาพของเครือข่าย การใช้ Root Guard เป็นเพียงมาตรการป้องกันเพิ่มเติมเท่านั้น

ประโยชน์ของการใช้ Root Guard

  • ป้องกันการเปลี่ยนแปลงโครงสร้าง STP โดยไม่ได้ตั้งใจ
  • รักษาเสถียรภาพของเครือข่ายในกรณีที่มีการเชื่อมต่อสวิตช์ใหม่เข้ามา
  • ช่วยป้องกันปัญหา network loop ที่อาจเกิดขึ้นจากการเปลี่ยนแปลง Root Bridge
  • ลดความเสี่ยงในการโจมตีแบบ STP manipulation attack

ความแตกต่างระหว่าง Root Guard และ BPDU Guard

คุณสมบัติ Root Guard BPDU Guard
การทำงาน บล็อคเฉพาะ Superior BPDU บล็อคทุก BPDU
วิธีกลับสู่สถานะปกติ อัตโนมัติ เมื่อไม่มี Superior BPDU ต้องรีเซ็ตด้วยคำสั่ง (err-disable recovery)
การใช้งาน ใช้กับ Designated Port ใช้กับพอร์ตที่เชื่อมต่อกับอุปกรณ์ปลายทาง
จุดประสงค์ ป้องกันการเปลี่ยน Root Bridge ป้องกันการส่ง BPDU จากอุปกรณ์ปลายทาง
